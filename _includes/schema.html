{%- comment -%} =============================================================================== schema.html - the site's entire structured-data (JSON-LD) layer =============================================================================== Emits ONE @graph per page. Every page carries the same Organization and WebSite nodes under stable @ids, so search engines and AI assistants resolve eJukebox as a single entity with many pages rather than 40 loose documents. Page-specific nodes (Service, FAQPage, HowTo, Product) are generated automatically from front matter and _data, so there is no hand-written JSON to drift out of date. Entity facts live in _data/org.yml. Prices live in _data/pricing.yml. Nothing is hard-coded here. --------------------------------------------------------------------------- WHAT GENERATES AUTOMATICALLY (no per-page work) --------------------------------------------------------------------------- layout: venue -> Service + audience + areaServed, and FAQPage if the page has `faqs:` (which every venue page already has) /products.html -> Product + Offer per tier, straight from pricing.yml every page -> WebPage + BreadcrumbList + Organization + WebSite noindex: true -> nothing at all is emitted --------------------------------------------------------------------------- PER-PAGE FRONT MATTER (all optional) --------------------------------------------------------------------------- schema_page_type: ContactPage # AboutPage, FAQPage, CollectionPage... schema_service: Voice announcements for venues # adds a Service node last_reviewed: 2026-08-28 # emits dateModified; omit rather than fake it faqs: # -> FAQPage - q: ... a: ... howto: # -> HowTo name: How to start a free trial description: ... total_time: PT2M # ISO 8601 duration supply: [An Australian mobile number] tool: [Any web browser] steps: - name: ... text: ... url: /free-trial.html#form # optional deep link mentions: # -> entity links (authority signal) - name: OneMusic Australia url: https://onemusic.com.au/ type: Organization schema_app: # -> SoftwareApplication name: eJukebox Controller description: ... os: [Android, iOS] schema_article: # -> Article (explainer/research pages only) headline: ... section: ... extra_schema: > # raw JSON node(s), appended verbatim. {"@type":"...", ...} # escape hatch for genuine one-offs.
